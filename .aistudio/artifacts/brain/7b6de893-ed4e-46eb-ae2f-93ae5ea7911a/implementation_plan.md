### 1. Overview & Core Concept

- **What It Does**: Delivers an all-in-one hiring and candidate platform landing page where Indian freshers and experienced professionals connect with top employers. It communicates trust, scale (2 Lakh+ talent pool), and ease of use through a modern, welcoming visual identity.
- **Target Audience / Persona**:
  - **Employers & Recruiters**: Looking to hire verified freshers, interns, and experienced specialists across 10 core categories without lengthy recruitment cycles.
  - **Job Candidates & Students**: Looking to build a professional profile, create an ATS-ready resume, and get discovered by employers for free.
- **Key Value**: Immediate clarity, frictionless browsing of pre-screened talent, and direct access to tools (Resume Builder, Profile Showcase, Talent Directory).

### 3. Key Product Decisions & Trade-Offs

- **Decision 1: Pixel-Faithful Component Architecture vs. Legacy Code**:
  - *Chosen Approach*: Implement a dedicated `GlitreadLandingPage.tsx` component that encapsulates all 11 sections with clean state handling, keeping other pages (Jobs, Resume Builder, Portfolio) fully linked and accessible.
  - *Why*: Ensures zero deviation from the screenshot while preserving all underlying tools.
- **Decision 2: Image Generation Strategy for 3D Characters**:
  - *Chosen Approach*: Generate high-fidelity 3D illustrated assets in a single batch turn using `generate_image`, capturing the Pixar/modern 3D tech character style seen in the screenshot.
  - *Why*: Matches the aesthetic of the reference without resorting to broken external URLs.
- **Decision 3: Interactive Candidate Filtering & Modals**:
  - *Chosen Approach*: Connect the candidate directory search directly to the 4 featured candidates with real-time text, experience, and location filtering. Provide quick interactive slide-over modals for "Hire Talent" and "Sign Up".
  - *Why*: Delivers an engaging, functional user experience instead of static mockups.

#### State & Data Handlers
- `searchQuery`, `selectedExperience`, `selectedLocation`: Controls candidate card filtering.
- `expandedFaqIndex`: Tracks open accordion question index (0 to 4).
- `isHireModalOpen`, `isCandidateModalOpen`: Controls action modal states.
- `savedProfiles`: Set of bookmarked candidate profile IDs.
